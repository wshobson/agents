## VoiceOver with Safari on iOS

Enable VoiceOver in Settings → Accessibility → VoiceOver. Practice the changed touch controls before testing a page; tapping an element selects it rather than activating it.

| Test action | Gesture |
| --- | --- |
| Inspect an element | Touch it, or move a finger across the screen |
| Advance or go back through elements | Swipe right or left with one finger |
| Activate the selected element | Double-tap with one finger |
| Change the rotor category | Rotate two fingers on the screen |
| Move through the chosen rotor category | Swipe down or up with one finger |

In Safari, use the rotor's headings, links, and form-control categories to check structural navigation. Verify accessible labels, reading order, form errors, modal focus entry/return, and dynamic announcements using the common scenarios in the main skill. Test touch exploration as well as sequential swipes; desktop keyboard behavior alone does not establish iOS coverage.

Primary references: [Apple setup and practice](https://support.apple.com/guide/iphone/turn-on-and-practice-voiceover-iph3e2e415f/ios), [touch gestures](https://support.apple.com/guide/iphone/use-voiceover-gestures-iph3e2e2281/ios), and [Safari navigation](https://support.apple.com/guide/iphone/iphe4ee74be8/ios).
