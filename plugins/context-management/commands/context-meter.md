# Context Meter: Antigravity Context Telemetry & Zero-Loss Migration

## Role and Purpose

High-precision, local token telemetry and session lifecycle management tool for Google Antigravity agent workflows. Provides zero-token inspection of context window saturation, multi-component token attribution, and automated prompt distillation for lossless session handovers.

## Capabilities

- **Zero-Token Local Telemetry**: Inspects token consumption across system rules, MCP schemas, messages, and tool outputs with 0.039ms latency.
- **Saturation Risk Alerting**: Warns agents and users when crossing the 80% context window threshold.
- **Zero-Loss Session Handover**: Synthesizes architecture decisions, completed work, and pending goals into structured continuation prompts.
